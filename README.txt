# BLOODY FIRE — сайт мода DOOM 2

Готовый одностраничный сайт для GFD (ГДФ) / BLOODY FIRE.

## Как запустить
1. Распакуй архив.
2. Открой `index.html` в браузере.
3. Ничего устанавливать для просмотра сайта не нужно.

## Что можно добавить
- настоящие ссылки на скачивание `gfdBETA*.wad`;
- Discord/Telegram/YouTube;
- больше скриншотов;
- описание оружия, врагов и эпизодов;
- историю обновлений.

В папке `assets` лежат подготовленные изображения из присланных скриншотов.
